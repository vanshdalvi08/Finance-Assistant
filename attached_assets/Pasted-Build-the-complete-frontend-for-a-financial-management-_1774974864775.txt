A clean, modern, professional, and minimal fintech UI that handles:
• Dashboard (with graphs and summaries)

• Next.js 14 (App Router)
• TypeScript
• Tailwind CSS
• ShadCN UI components
• Recharts for charts (bar, line, pie)
• Zustand or Context API for state
• Axios or fetch for API calls (but backend not required in this prompt)
• Lucide icons

Overall UI Style:
• Premium fintech look
• Soft colors: slate gray, deep blue, white
• Rounded corners, subtle card shadows
• Smooth hover states, transitions
• Fully responsive layout
